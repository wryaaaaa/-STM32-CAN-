# 硬件接线图

## 一、传感器采集节点

```
┌──────────────────────────────────────────────────────────┐
│                  STM32F103C8T6 (最小系统板)                │
│                                                          │
│  PB3 ────┬──── LED1 (通过 220Ω 限流电阻 → GND)            │
│  PB4 ────┼──── LED2 (通过 220Ω 限流电阻 → GND)            │
│          │                                               │
│  PB5 ────┼──── DHT11 DATA                               │
│          │    ┌──────────┐                               │
│          │    │  DHT11   │                               │
│          │    │ 1 VCC ──── 3.3V                         │
│          │    │ 2 DATA─── PB5                           │
│          │    │ 3 NC ──── 悬空                           │
│          │    │ 4 GND ─── GND                           │
│          │    └──────────┘                               │
│          │         DATA 引脚接 4.7kΩ 上拉电阻到 3.3V     │
│          │                                               │
│  PB8 ────┼──── TJA1050 CAN_RX (TJA1050 的 RXD 引脚)      │
│  PB9 ────┼──── TJA1050 CAN_TX (TJA1050 的 TXD 引脚)      │
│          │                                               │
│    3.3V──┼──── TJA1050 VCC                               │
│     GND──┼──── TJA1050 GND                               │
│          │                                               │
│          │    ┌──────────────┐                            │
│          │    │   TJA1050    │                            │
│          │    │ 1 TXD ────── PB8 (CAN_RX)                │
│          │    │ 2 GND ────── GND                         │
│          │    │ 3 VCC ────── 5V (推荐) 或 3.3V           │
│          │    │ 4 RXD ────── PB9 (CAN_TX)                │
│          │    │ 5 Vref ───── 悬空/3.3V                   │
│          │    │ 6 CANL ───── CAN_L 总线                  │
│          │    │ 7 CANH ───── CAN_H 总线                  │
│          │    │ 8 RS ────── GND (斜率电阻模式)            │
│          │    └──────────────┘                            │
│          │                                               │
│   CAN_H 端接: 120Ω 电阻 ─ CAN_H ─ CAN_L (总线两端各一个)  │
└──────────────────────────────────────────────────────────┘
```

### 传感器节点接线速查表

| STM32 引脚 | 外设 | 说明 |
|-----------|------|------|
| PB3 | LED1 阳极 | 通过 220Ω → GND，采集指示 |
| PB4 | LED2 阳极 | 通过 220Ω → GND，告警指示 |
| PB5 | DHT11 DATA | 需 4.7kΩ 上拉到 3.3V |
| PB8 | TJA1050 RXD | CAN 接收 |
| PB9 | TJA1050 TXD | CAN 发送 |

## 二、网关节点

```
┌──────────────────────────────────────────────────────────┐
│                  STM32F103C8T6 (最小系统板)                │
│                                                          │
│  PB3 ────┬──── LED1 (通过 220Ω 限流电阻 → GND)            │
│  PB4 ────┼──── LED2 (通过 220Ω 限流电阻 → GND)            │
│          │                                               │
│  PA9 ────┼──── ESP8266 RX (ESP模块的 RXD 引脚)            │
│  PA10 ───┼──── ESP8266 TX (ESP模块的 TXD 引脚)            │
│          │    ┌─────────────┐                             │
│          │    │  ESP8266    │                             │
│          │    │ VCC ─────── 3.3V (峰值 ≥300mA)            │
│          │    │ GND ─────── GND                           │
│          │    │ TXD ─────── PA10 (STM32 RX)               │
│          │    │ RXD ─────── PA9  (STM32 TX)               │
│          │    │ CH_PD ───── 3.3V (使能)                    │
│          │    │ RST ─────── 3.3V (通过10kΩ, 不悬空)        │
│          │    └─────────────┘                             │
│          │                                               │
│  PB8 ────┼──── OLED SCL (软件I2C时钟)                     │
│  PB9 ────┼──── OLED SDA (软件I2C数据)                     │
│          │    ┌──────────────┐                            │
│          │    │ OLED SSD1306 │                            │
│          │    │ VCC ──────── 3.3V                        │
│          │    │ GND ──────── GND                         │
│          │    │ SCL ──────── PB8                         │
│          │    │ SDA ──────── PB9                         │
│          │    └──────────────┘                            │
│          │                                               │
│  PB8 ────┼──── TJA1050 CAN_RX                            │
│  PB9 ────┼──── TJA1050 CAN_TX                            │
│          │    接线同传感器节点                             │
└──────────────────────────────────────────────────────────┘

⚠ 注意: OLED 和 TJA1050 共用 PB8/PB9！
   这两个是 CAN 的默认复用引脚，OLED 用的是软件 I2C 位操作。
   实际接线时，CAN 使用 STM32 硬件 CAN 控制器 (PB8=CAN_RX, PB9=CAN_TX)，
   而 OLED 需要改用其他引脚。

   推荐方案: OLED 改用 PB6 (SCL) + PB7 (SDA)
   或: PA5 (SCL) + PA6 (SDA)

   以下接线图使用 PB6/PB7 避免冲突 ↓
```

### 网关节点接线速查表（修正后）

| STM32 引脚 | 外设 | 说明 |
|-----------|------|------|
| PB3 | LED1 阳极 | 通过 220Ω → GND |
| PB4 | LED2 阳极 | 通过 220Ω → GND |
| PA9 | ESP8266 RXD | UART1 TX |
| PA10 | ESP8266 TXD | UART1 RX |
| **PB6** | OLED SCL | 软件 I2C 时钟 |
| **PB7** | OLED SDA | 软件 I2C 数据 |
| PB8 | TJA1050 RXD | CAN 接收 |
| PB9 | TJA1050 TXD | CAN 发送 |

> ⚠ 如果你用的是现成的 OLED 模块且 SCL/SDA 固定在 PB8/PB9，则需要把 CAN 改为软件模拟到其他引脚，或者使用硬件 I2C 的 PB6/PB7 来驱动 OLED。

## 三、CAN 总线连接

```
  传感器节点                           网关节点
  ┌─────────┐                        ┌─────────┐
  │ TJA1050 │                        │ TJA1050 │
  │  CANH 6 ├───┬────────────────┬───┤  CANH 6 │
  │  CANL 7 ├───┼── 双绞线 ──────┼───┤  CANL 7 │
  └─────────┘   │                │   └─────────┘
                │   120Ω         │      120Ω
                ├───▓▓▓▓────GND──┤
                │                │
                └────────────────┘

  要求:
  - 双绞线: 传输距离 ≤30 米
  - 终端电阻: 总线两端各接一个 120Ω (1/4W 即可)
  - 共地: 两个节点的 GND 建议连接在一起
```
